# Bash

## Что такое Bash

`Bash` — это командная оболочка в Linux. Через нее можно вводить команды в терминале, а еще писать небольшие скрипты для автоматизации.

Например, с помощью `bash` можно:

- запускать несколько команд подряд
- работать с файлами и папками
- делать простые административные задачи
- писать скрипты для повторяющихся действий

## Что нужно, чтобы файл запускался как скрипт

Чтобы файл можно было выполнить как скрипт, обычно нужно следующее.

### 1. Указать интерпретатор

В первой строке файла обычно пишут `shebang`, чтобы система понимала, чем запускать скрипт:

```bash
#!/usr/bin/env bash
```

Иногда пишут и так:

```bash
#!/bin/bash
```

### 2. Дать файлу право на выполнение

Например:

```bash
chmod +x script.sh
```

### 3. Файл должен быть обычным текстовым файлом

Внутри должны быть команды, которые понимает shell. Простейший пример:

```bash
#!/usr/bin/env bash
echo "Hello"
```

### 4. Запускать из текущей директории

Если файл исполняемый, его можно запустить так:

```bash
./script.sh
```

Если права на выполнение не выданы, можно запустить через сам `bash`:

```bash
bash script.sh
```

## Что еще важно

- расширение `.sh` использовать удобно, но это не обязательное требование
- файл должен быть сохранен без лишнего форматирования, как обычный текст
- если запуск идет через `./script.sh`, файл должен находиться в текущей директории
- права можно проверить командой `ls -l`

## Полезные команды

- `chmod +x script.sh` — сделать файл исполняемым
- `ls -l script.sh` — посмотреть права
- `bash script.sh` — запустить через `bash`
- `./script.sh` — запустить как обычный исполняемый файл
