# Load Average

## Что это такое

`Load Average` — это среднее количество задач, которые:

- выполняются на CPU прямо сейчас
- готовы к выполнению
- находятся в состоянии непрерываемого ожидания, чаще всего из-за дискового I/O

Обычно показываются три числа:

- за 1 минуту
- за 5 минут
- за 15 минут

Пример:

```text
load average: 0.42, 0.71, 0.95
```

## Где посмотреть

- `uptime`
- `w`
- `top`
- `cat /proc/loadavg`

## Как интерпретировать

Смотреть `Load Average` удобно относительно количества логических CPU.

Примеры:

- для 1 CPU значение `1.00` означает, что процессор загружен примерно полностью
- для 4 CPU значение `4.00` означает примерно полную загрузку системы
- если значение заметно выше числа CPU, часть задач уже стоит в очереди и ждет ресурсы

## Важные нюансы

- `Load Average` не равен проценту загрузки процессора
- высокий `Load Average` может появляться не только из-за CPU, но и из-за ожидания диска
- краткий всплеск в первом числе не всегда проблема, важнее смотреть на динамику всех трех значений

Пример чтения метрики:

- `0.20 0.30 0.25` — система почти не нагружена
- `6.00 5.50 5.10` на машине с 4 CPU — нагрузка выше доступных ресурсов
- `8.00 2.00 0.70` — резкий недавний всплеск нагрузки

## Практический вывод

`Load Average` полезен для быстрой диагностики. Если он растет, дальше обычно проверяют:

- `top` или `htop` — кто нагружает CPU
- `iostat`, `iotop` — нет ли проблем с диском
- `vmstat` — нет ли очередей и блокировок
