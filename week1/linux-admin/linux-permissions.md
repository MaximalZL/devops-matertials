# Права доступа к файлам в Linux

## Категории прав

В Linux права доступа задаются для трех категорий:

- `u` (`user`) — владелец файла
- `g` (`group`) — группа файла
- `o` (`others`) — остальные пользователи

Часто все три категории вместе обозначают как `a` (`all`).

## Базовые права

- `r` (`read`) — чтение
- `w` (`write`) — запись
- `x` (`execute`) — выполнение

Для каталогов смысл немного отличается:

- `r` — читать список файлов
- `w` — создавать, удалять и переименовывать файлы внутри каталога
- `x` — заходить в каталог и обращаться к объектам внутри него

## Как права выглядят в системе

Команда:

```bash
ls -l
```

Пример:

```text
-rwxr-xr--
```

Разбор:

- первый символ — тип объекта
- `rwx` — права владельца
- `r-x` — права группы
- `r--` — права остальных

## Числовая форма

Каждому праву соответствует число:

- `r = 4`
- `w = 2`
- `x = 1`

Суммируя их, получают восьмеричную запись:

- `7 = rwx`
- `6 = rw-`
- `5 = r-x`
- `4 = r--`

Частые примеры:

- `644` — владелец читает и пишет, остальные только читают
- `755` — владелец читает, пишет, выполняет; остальные читают и выполняют
- `600` — доступ только у владельца
- `700` — полный доступ только у владельца

## Основные команды смены прав

### chmod

Изменяет права доступа.

- `chmod 644 file.txt`
- `chmod 755 script.sh`
- `chmod u+x script.sh`
- `chmod g-w file.txt`
- `chmod o-r file.txt`
- `chmod -R 755 dir/`

### chown

Меняет владельца файла или каталога.

- `chown user file.txt`
- `chown user:group file.txt`
- `chown -R user:group dir/`

### chgrp

Меняет группу файла.

- `chgrp developers file.txt`

## Практические примеры

- сделать скрипт исполняемым: `chmod +x script.sh`
- закрыть приватный файл для остальных: `chmod 600 secret.txt`
- выдать типичные права каталогу сайта: `chmod 755 public/`
