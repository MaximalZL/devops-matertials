# Git

## Что такое Git

`Git` — это система контроля версий. Она позволяет отслеживать изменения в файлах, сохранять историю проекта и работать над одним репозиторием в одиночку или в команде.

С помощью `git` можно:

- сохранять изменения по шагам
- смотреть историю правок
- возвращаться к прошлым версиям
- работать в отдельных ветках
- отправлять изменения в удаленный репозиторий

## Основные команды

### Инициализация репозитория

```bash
git init
```

Создает новый Git-репозиторий в текущей директории.

### Проверка состояния

```bash
git status
```

Показывает, какие файлы изменены, какие уже добавлены в индекс и что готово к коммиту.

### Добавление файлов

```bash
git add file.txt
git add .
```

`git add` добавляет файлы в индекс перед коммитом.

### Создание коммита

```bash
git commit -m "Initial commit"
```

Сохраняет текущее состояние добавленных файлов в историю.

### Просмотр истории

```bash
git log
git log --oneline
```

Показывает историю коммитов.

### Просмотр изменений

```bash
git diff
git diff --staged
```

Показывает разницу между версиями файлов.

### Работа с ветками

```bash
git branch
git branch feature
git checkout feature
git switch feature
```

Основные действия с ветками: посмотреть список, создать новую и перейти в нее.

### Слияние веток

```bash
git merge feature
```

Объединяет изменения из одной ветки в другую.

### Работа с удаленным репозиторием

```bash
git remote -v
git push
git pull
git clone <url>
```

Эти команды используют для связи с удаленным репозиторием.

## Часто используемая последовательность

Пример обычной работы:

```bash
git status
git add .
git commit -m "Update files"
git push
```

## Полезные команды

- `git restore file.txt` — убрать локальные изменения в файле
- `git rm file.txt` — удалить файл из репозитория
- `git mv old.txt new.txt` — переименовать файл
- `git fetch` — получить изменения с удаленного репозитория без слияния
- `git show` — показать содержимое коммита
